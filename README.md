---------Introducion---------
Nuestro programa es un algoritmo cuyo fin es extraer los datos de un archivos csv en formato listas de dicionarios
modificar esa lista de distintas formas y guardar esos cambios en el archivo csv
---------Instruciones---------
1 iniciar el programa 
2 introducir el nombre del archivo verifica si existe sino existe puede crear uno con ese nombre
3 selecionar una opcion del menu
4 opciones
        1. Buscar un país
        2. Filtrar un país
        3. Ordenar países
        4. Mostrar estadísticas
        5. Agregar país
        6. Modificar país
        7. Guardar cambios en el archivo
        8. Salir
5 salir (si no guardaste los cambios te da la opcion de guardarlos)
---------Ejemplos---------
Iniciar programa
Ingresar como nombre de archivo "archivo_paises"
selecionar la opcion 1
Ingresar ar
te mostrara los datos de argentina y arabia
ingrese la opcion 3
selecionar la de ordenar paises por poblacion de mayor a menor
En el menu pricipal selecionar la 7 y ahora si abris el archivo csv deberia estar ordenado como lo modificaste
